# Single-walker continuum protocol: implementation and validation plan

This is an R&D design and verification protocol, not an equilibrium certificate
or an established speed-up. The separate opt-in engine has now been implemented
and verified on small continuum targets, including deliberately capped controls
and an exactly solvable, untruncated physical hard-sphere control; dense
fluid–solid validation is not completed. This document is not part of the manuscript or
Supplemental Material, and does not change the earlier replica production
sampler. The existing many-replica runs revealed persistent
phase-bank and number-occupancy memory; replacing that bank by one host removes
that particular replicated inventory, but does not by itself remove free-energy
barriers or establish fluid–solid equilibrium.

## Probability space and exact extended target

Let the periodic cubic box be the torus
`T_L = R^3 / (L Z)^3`, of volume `V = L^3`. Let `X_K` be the space of unordered,
finite simple point configurations in this torus with at most `K` host particles.
It includes the empty configuration. Equip it with the Borel sigma-algebra
generated by the counting maps `eta -> eta(D)` for Borel sets `D` of the torus.
Let `J` be a finite set of auxiliary nodes with the discrete sigma-algebra. The
sample space is

`Omega = J × X_K × T_L`, with its product sigma-algebra.

A realization is `omega = (j, eta, q)`: current node, host configuration, and
auxiliary/cavity center. The common configuration reference measure is the
sector measure `M_K`, defined for every nonnegative measurable `F` by

`∫ F(eta) M_K(d eta) = Σ_{n=0}^K (1/n!) ∫_{T_L^n} F({r_1,...,r_n}) d r_1...d r_n`.

The empty-sector integral is `F(empty)`. Coincident coordinates have Lebesgue
measure zero. The auxiliary center measure is normalized Haar measure `d q/V`.

At node `j`, let `zeta_j > 0` be the activity (units inverse volume), and let
`Phi_j(eta,q)` be the dimensionless potential. It can include the pair-overlap
penalty, the deterministic seven-mode order umbrella, the number umbrella, and
hard pair/cavity support indicators through infinite penalties. All such
functions and registry tie rules must be deterministic functions of the current
configuration; a reference registry is a proposal or observable, not a physical
constraint. Let `b_j` be a finite dimensionless tempering weight. Define

`Pi(d omega) = Z_ext^{-1} e^{b_j} zeta_j^{N(eta)} e^{-Phi_j(eta,q)} M_K(d eta) d q/V`,

with summation over `j`, and

`Xi_j = ∫ zeta_j^{N(eta)} e^{-Phi_j(eta,q)} M_K(d eta) d q/V`,
`Z_ext = Σ_j e^{b_j} Xi_j`.

The empty host has positive weight at every finite-parameter node, so each
normalizer is positive. The finite cap and finite node set make the normalizers
finite for the proposed nonnegative penalties. Exactly,

`Pi(eta,q | j) = Xi_j^{-1} zeta_j^{N(eta)} e^{-Phi_j(eta,q)} M_K(d eta) d q/V`,
`Pi(j) = e^{b_j} Xi_j / Z_ext`.

Thus any finite frozen `b_j` preserves the physical conditional law. Approximate
`b_j = -log Xi_j + constant` makes node visitation more even, but inaccurate
weights affect efficiency, not that conditional-law identity.

Every physical node must have the actual hard-sphere diameter and zero order and
number umbrella strengths. Physical cavity nodes share the chosen physical
activity. A physical cap is certified nontruncating by the periodic disjoint-ball
bound `N pi sigma^3/6 <= V`, provided `L >= sigma`; the conservative choice
`K >= ceil(6V/(pi sigma^3))` therefore suffices. The auxiliary ideal/soft ensembles
may be capped; their truncation changes their own normalizers, not the conditional
untruncated physical target. An artificially small cap is permissible only in a
test whose explicitly stated target is the capped law.

## Lazy, degree-corrected node hops

Use a connected undirected auxiliary graph and retain the entire configuration
`(eta,q)` when proposing an ordinary node hop. With probability, for example,
`1/2`, make no hop. Otherwise choose a neighbor uniformly. If `d_j` is the node
degree, the Metropolis–Hastings acceptance for `j -> k` is

`min(1, exp[b_k-b_j + (x_k-x_j) N - Phi_k + Phi_j] d_j/d_k)`,

where `x_j = log zeta_j` in the fixed simulation volume unit. A configuration
outside the destination support is rejected. General asymmetric graph proposals
instead require their exact reverse/forward proposal-density ratio. Omitting the
degree factor on an irregular graph changes the invariant node weights. Lazy
hops remove a possible bipartite-graph periodicity and support a simple
empty-state irreducibility argument.

Existing exact within-node kernels can be reused, subject to independent actual
code tests. A normalized state-dependent insertion density `g_eta(r)` needs birth
ratio `zeta_j exp(-Delta Phi_j)/[(N+1) g_eta(r)]`; uniform-particle deletion needs
the reverse density recomputed from the post-deletion configuration. Number,
order, and pair costs must all enter the full target difference. A graph hop does
not change coordinates or caches, but its target costs must be recomputed for the
destination parameters. Composing invariant within-node and hop kernels preserves
`Pi`; reversibility of the complete ordered sweep is not required.

## Optional exact conditional node-label heatbath

Holding the current host and center `y=(eta,q)` fixed, the full conditional is

`G(j | y) = exp[b_j + x_j N(eta) - Phi_j(eta,q)] / sum_k exp[b_k + x_k N(eta) - Phi_k(eta,q)]`.

The common factorial sector measure and normalized center measure cancel. This
is a Gibbs conditional, not a graph-neighbor proposal; no node-degree factor is
present. For fixed `y`, `Pi(j,y) G(k|y) = Pi(k,y) G(j|y)`. Thus it can be composed
with the existing exact local and degree-corrected neighbor/tagged kernels while
preserving the same extended law. There is no claim that the complete ordered
composition is reversible.

If this update follows an accepted tagged move, it must use the new host count,
order and center-to-host minimum distance, not the pre-hop observation row.
Deleting a tag changes the host and puts the center at the deleted position;
restoring a tag changes the host and draws a fresh base center. Hard tagged
endpoints have zero pair-overlap count before and after, but a generic helper
should reconstruct all costs from the actual current configuration. With the
present equal-diameter guard, one current pair count is sufficient for all nodes.
Use a stable categorical draw: set unsupported scores to negative infinity,
subtract the largest finite score, normalize positive exponentials, and treat an
all-invalid input as a state error rather than silently continuing. Rejected and
repeated labels remain full-clock dwells. The heatbath option, update order and
separate counters must be explicit in frozen provenance; the legacy option-off
path must preserve its random-number sequence.

This update removes nearest-neighbor label diffusion, not the need for host
particle loss or structural melting. On the hard activity path its score is
`b_j+x_j N`; an upper-activity host cannot reach the gas merely because all
geometrical supports are compatible. In addition, a tagged cavity center makes
both base and cavity supports valid, with conditional cavity/base score ratio
`exp(b_c-b_b)`. This can be very large at high activity. The separate tagged MH
restoration, which changes the host and refreshes the base center, must not be
silently replaced by the fixed-configuration Gibbs update.

For finite cap `K`, finite frozen weights, nonnegative costs and an unbiased
ideal node `I`, the ideal-label conditional has the uniform mathematical bound

`G(I|eta,q) >= epsilon_G = 1 / sum_j exp[b_j-b_I+K max(x_j-x_I,0)] > 0`.

After selecting the ideal label, the existing explicit one-half lazy neighbor
branch leaves it there. The next incoming-ideal sweep refreshes the entire host
and center, and the ideal local kernel preserves that refreshed conditional
law. Consequently the pre-hop observation-chain kernel on the physical state
minorizes `(epsilon_G/2)(delta_I × pi_I)`. Absolute clock indices, diagnostic
counters and unused storage slots are not part of this stationary state. This
gives a finite-cap formal uniform-ergodicity/regeneration route, not a practical
dense mixing rate or a claim that arbitrarily tiny probabilities are resolved
by floating-point sampling. Actual frozen reservoir returns must still be
demonstrated.

The independent exact finite-state tests in
`tests/test_single_walker_conditional_label_graph.py` cover stationary Gibbs
conditionals with unequal activities, soft/order/number penalties and caps,
composition with the tagged-neighbor kernel, and explicit failures from degree
factors or stale post-tag features. Eight tests pass, including the uniform
reservoir minorization on an independently enumerated finite model. They
establish the formula and test design, not dense mixing. The implemented optional
engine placement is after the
recorded local observation and before the existing lazy/Palm step, so that the
current features remain valid after a label-only Gibbs update. This compound
label protocol requires explicit pre-neighbor labels and separate Gibbs
counters; adjacent full-clock rows no longer identify a single neighbor move.

Independent actual-helper and continuum-composition controls in
`tests/test_single_walker_gibbs_helper_independent.py` and
`tests/test_single_walker_gibbs_continuum_equilibrium.py` passed all ten tests in
14.36 seconds. They compare support/cost probabilities with an independent
log-sum-exp calculation, check stable categorical draws and gauge invariance,
and reuse the unchanged unequal-activity, analytic unit-torus and soft/order/
number partition reference laws with the Gibbs option enabled. Every chunk's
pre-neighbor and final labels reproduce the distinct Gibbs/neighbor counters;
full-clock moments, work and saved support/center checks pass. These are
small-target implementation controls, not a certificate for a dense pilot.

## Optional cavity-radius relaxation loop

At one fixed physical activity, a branch of legitimate cavity targets from
`R=0` to `R=sigma` can be connected by ordinary radius/support hops, with its
matched endpoint closed back to the base by the exact tagged move. A path
`base -> tagged deletion -> R=sigma -> smaller R -> base` can remove one host
particle without immediately undoing that deletion. The reverse path grows a
compatible cavity and restores the tagged particle. All intermediate targets
are ordinary hard-cavity conditional ensembles, not registry or occupancy
constraints. No altered target or guessed physical phase weight is needed.

Five exact controls in `tests/test_single_walker_cavity_radius_ring.py` establish
the full finite-state joint stationary law and equal forward/reverse equilibrium
flux for explicit number-changing loops. This is a design control only. Global
label Gibbs already permits leaving the matched cavity while keeping the host
number, so the extra radius branch is not the first possible escape once Gibbs
is enabled. Its possible benefit is staged geometrical and host relaxation.
Neither the total cavity work contrast nor vacancy/phase barriers are assumed
to disappear; actual continuum controls and measured mixing are required before
an efficiency claim.

The actual-engine gate in
`tests/test_single_walker_continuum_radius_ring.py` passed in 9.73 seconds.
It uses the exactly solvable unit torus, common activity `zeta=.2`, physical
radii `0,.25,.5,1`, and a capped ideal auxiliary. For `R<=.5`, the physical
normalizer is exactly `Xi_R=1+zeta(1-4 pi R^3/3)`; at the matched radius it is
`Xi_1=1`. The geometry permits at most one hard host, so cap two is physically
nontruncating. A 120,000-step Gibbs-enabled full-clock control agrees with the
joint/conditional number laws, annular probabilities, work and Palm/Fano
identities, and independently replays all label buffers/counters and saved
centers/support. It also records tagged deletion followed by visits to every
shrinking-radius stage and an empty-base return, demonstrating the implemented
number-transport mechanism. Such substep paths are diagnostic, not equilibrium
reward estimators. No force or phase-coexistence claim is made on this tiny
geometry; dense validation remains a separate requirement.

## Post-native-v3 design: a dense ideal and soft multi-route bridge

The closed native-v3 pilot illustrates the distinction between reservoir
access and dense regeneration. Its 200,000 frozen steps contain 511 ideal
refreshes and 510 complete cycles, but every complete cycle has zero base and
matched-cavity dwell. The base/cavity observations occur only in the leading
incomplete part, and the subsequent host number never exceeds 25. Therefore
neither adaptive flatness nor those reservoir returns supplies a dense
fluid--solid equilibrium result. The next design must enable creation of dense
hosts after an actual refresh, not preserve the initial dense host longer.

The smallest supported change is a native reconstruction of the existing
compact soft-pair/order graph, retaining the single-host engine and its exact
conditional target. Use the unbiased soft `gamma=0`, `kappa=nu=0` node at
`x=log(1/1.06448)` as the designated ideal reservoir. Its exact capped-Poisson
refresh has mean approximately 29 in the current box and independent Haar
positions/center. It is a disordered dense cloud with fluctuating count, not a
preformed crystal or a fixed-count initialization. Finite pair penalties then
permit insertion and rearrangement without first finding a full hard-sphere
void. The physical base and cavity retain their chosen `x`, hard pairs, and zero
order and number biases.

Two removable auxiliary routes share that reservoir and the same physical
base. A low-order route uses the existing fluid-number preference near 29.
An ordered route can introduce a finite `nu(N-32)^2` preference gradually before
soft ordering at `gamma=2`, maintain it while ordering/hardening, and remove it
gradually before physical observations. A direct jump from zero to `nu=4` would
cost 36 dimensionless units for a host at `N=29`, so overlap between successive
number-bias stages matters. All number sectors remain mathematically allowed
at finite penalties; no fixed count, occupancy rule or physical phase odds are
introduced. Order and number penalties must both vanish at every physical
node, including the matched-cavity/radius path.

The number umbrella is not an occupancy umbrella. A 32-particle soft host can
have empty and multiply occupied reference sites, and a high Fourier order can
occur without a valid crystal. Record pair overlaps, empty/excess sites,
registry RMS and independent bond order. Strong number bias can suppress
vacancy birth/death repair, so ordinary displacement relaxation and gradual
bias removal remain necessary. The common configuration sector measure is still
`M_K` with its single `1/N!` factor. No additional crystal-fragment combinatorial
factor is inserted: reference fitting is a diagnostic/proposal, not a restricted
crystal coordinate domain.

Native construction is preferable to treating the old 163-node replica history
as a free-energy or phase-weight source. Its target arrays can be reused as a
design, but the physical field, reservoir, removable number stages, shared
base and radius path must be explicit. Any initial weights remain efficiency
guesses. Staged calibration is discarded and all arrays/weights are frozen
before production. Label flatness and stable auxiliary number means are
especially weak evidence when a number umbrella deliberately enforces those
means.

The implemented native compact construction in
`scripts/continuum_tempering_graph.py` has 145 nodes before optional cavity
staging (160 with 16 radius intervals). Its ordered entry uses
`nu=.25,.5,1,2,4` at the `gamma=2` low-order gateway; the ordered route retains
`nu=4` with preferred count 32, then releases it through
`nu=2,1,.5,.25,.1,0` at finite pair penalty 25 before the hard physical base.
Both routes and the physical radius loop share that one base. The independent
pure controls in `tests/test_native_compact_number_target_independent.py`
reconstruct the exact capped ideal/number sector normalizers with `1/N!`,
check finite staged bias removal and connectivity, and exhibit a distinct-point
32-particle paired-site/empty-site configuration with high Fourier order but
invalid hard support. Construction and these target-law controls are separate
from the still-required dense frozen validation.

Before a dense result, require physical base/cavity rewards inside many complete
reservoir cycles, including independently verified fluid and crystal order
created after refresh. Check actual host-count and reference-occupancy
fluctuations, genuine creation/melting rather than merely auxiliary high order,
and the full reduced-Palm deletion predictions with common-cycle uncertainty.
All-fluid and crystalline starts should use identical frozen targets/weights
and be discarded through their first exact refresh. A finite-cell activity
scan, if needed to populate both physical basins, is a set of separately analyzed
physical targets; no imposed relative phase weight or pooling is permitted.

This is a transport design, not a promised speed-up. Staged open insertion has
established precedent in [Ashton and Wilding (2010)](https://arxiv.org/abs/1002.2844),
but their binary-mixture ghost algorithm differs from this whole-host bridge.
Their discussion also distinguishes staging from residual high-density packing
bottlenecks. [Wilding and Bruce (2000)](https://arxiv.org/abs/cond-mat/0009062)
provides phase-switch context, not a reason to import fixed-count crystal
fragment factors into the present full-host grand measure.

### Number-neutral residual-vacancy relocation

An additional opt-in conditional-position MH step addresses paired/empty-site
transport without relaxing the auxiliary number bias. Select one host particle
`r` uniformly, form the residual host `xi=eta\{r}`, and fit the deterministic
vacancy mixture `g_xi` to that residual only. Draw `r'` from the normalized
full-support mixture and accept with

`min(1, exp[-Phi_j(xi+r')+Phi_j(xi+r)] g_xi(r)/g_xi(r'))`.

The reverse residual is exactly the same `xi`. The uniform tag-selection
probability, activity, factorial and number-umbrella costs cancel because
the move preserves the host count. All pair/cavity and Fourier-order costs
remain in the acceptance ratio. The mixture sums every covering periodic
cube, retains a positive Haar component, and falls back to uniform when the
residual is too small or has no empty fitted site. Registry fitting defines
a proposal, not a crystal-state restriction or coordinate transformation.
Preferential selection of an excess-site particle would need an additional
forward/reverse selection factor; the implemented option uses uniform tags.

This step is default-off and preserves the old seeded trajectories when
disabled. Coordinates and the seven-mode cache change only on acceptance;
separate counters do not change the existing acceptance-column meanings.
The independent controls in
`tests/test_residual_vacancy_relocation_reference.py` and
`tests/test_continuum_vacancy_relocation_equilibrium_independent.py` include
periodic overlapping-cube normalization, exact finite-state stationary laws,
a missing-reverse-density counterexample, the unchanged nine-dimensional
hard/cavity/soft/order/number partition control, and an accepted/rejected
fixed-count Fourier-cache replay. The coordinated relocation/driver/provenance
subset passed all 40 controls in 27.71 seconds with approximately 746 MiB peak
resident memory and no swaps. These checks establish small-target correctness,
not a measured dense speed-up or physical phase equilibration. The additional
`tests/test_single_walker_vacancy_relocation_equilibrium_independent.py` control
enables relocation together with Gibbs in the actual single-walker wrapper:
its five-node capped partition laws, current features, label/counter replay
and saved support/cache/center checks passed separately in 12.11 seconds
with approximately 473 MiB peak resident memory and no swaps. A narrow vacancy
proposal can pay a substantial reverse-density penalty, so numerical conductance
and complete reservoir-cycle evidence are still required.

### Optional weaker number bias during hardening

The next declared graph variant retains number stiffness 4 on ordered-target
ramp nodes 21--38, then introduces two fixed-`gamma=2`, fixed-`B*=.88` nodes
with stiffness `sqrt(4H)` and `H`, where `0<H<4`. Hardening nodes 39--69 use
stiffness `H`; the finite-pair removal path uses
`H/2,H/4,H/8,H/16,H/40,0` before the unbiased hard physical base. The default
`H=4` adds no new relaxation nodes and reproduces all original target and
initial-weight bytes. The low-order route, physical activity/volume and
zero-bias physical endpoints remain unchanged.

This is relaxation after an ordered-target ramp, not evidence that a crystal
has already formed. In the closed relocation pilot, node 38 still had average
Fourier order near .51 and approximately 23 overlaps. At preferred count 32,
changing stiffness 4 to 1 removes three units of hypothetical deletion cost;
at count 31 it removes nine units. Those are exact saved-state log-odds changes,
not an equilibrium estimate or a prediction of transition counts. Weaker
number bias also permits larger soft clouds and interstitial/paired reference
assignments, so density, hard support, occupancy and independent bond order
must all be monitored. No reference-site factor or fixed-count domain enters
the full-host target.

The independent controls in
`tests/test_native_compact_hardening_number_independent.py` bind the default
to the immutable original artifact, reconstruct the complete weaker-bias

exhibit a high-Bragg overlapping 33-particle counterexample. The coordinated

Dense frozen validation of this variant remains separate from these checks.

## Discarded calibration and number-drift diagnostics

Finite adaptive calibration can improve efficiency without altering a later
frozen physical conditional law. All adaptive rows must be discarded; targets,
graph, proposal scales and weights must then be archived and frozen. Cumulative
label flatness alone does not show correct free-energy weights or phase
equilibration when the host number/order changes during calibration. Track
recent-epoch conditional number and order distributions and reservoir-to-physical
returns, then test regeneration under frozen weights.

For adjacent hard nodes `x_h>x_l`, define
`N_neutral=(b_l-b_h)/(x_h-x_l)`. Holding the host fixed, the score change towards
the lower node is `(x_h-x_l)(N_neutral-N)`; the neighbor-degree term belongs only
to its separate MH proposal. Raising the host count by `Delta N` suppresses this
score by `(x_h-x_l) Delta N`. A cumulative path barrier can therefore persist
despite moderate acceptance on every individual edge. Ideal flat-normalizing
hard weights satisfy `b(x)=-log Xi(x)+constant`, hence `b'(x)=-E_x N` and
`b''(x)=-Var_x N<=0`. Nondecreasing secant neutral numbers within `[0,K] are useful
free-energy-consistency diagnostics, not constraints on physical configurations
or equilibrium certificates. Arbitrary finite frozen weights still preserve
conditional targets even if these efficiency diagnostics fail.

### Positive nonuniform label allocations

Use `tau_j` for a desired **node-label** allocation, to distinguish it from the
cavity-center coordinate `q` and a physical phase probability. Require
`tau_j>0` and `sum_j tau_j=1`. For `J>3` distinct base, matched-cavity and ideal
nodes, the endpoint-priority policy is

`tau_base=.30`, `tau_cavity=.30`, `tau_ideal=.02`,
`tau_other=.38/(J-3)` for each remaining node.

These numbers request computational effort at labels; they prescribe neither
the fluid/solid probabilities nor a crystal occupancy within any label. They
leave every node's potential, activity, factorial sector measure and conditional
physical target unchanged. In particular, no crystal-fragment factor is added.

During discarded calibration only, update after the actual final updated label
`J_t` by

`b_j <- b_j + g_t [tau_j - 1{J_t=j}]`,

and fix the common additive gauge. For a frozen equilibrated extended law,
`p_j(b)=exp(b_j) Xi_j / sum_k exp(b_k) Xi_k`. Its expected unconstrained increment
is `g_t [tau_j-p_j(b)]`. Thus the unique relative **interior mean-field root** is

`b_j = log(tau_j) - log(Xi_j) + constant`.

Equivalently, the convex objective
`log(sum_j exp(b_j) Xi_j)-sum_j tau_j b_j` has gradient `p(b)-tau` and Hessian
`diag(p)-p p^T`, positive definite on the gauge-fixed subspace. This proves the
root and update direction, not convergence of a finite adaptive run. The
Markov chain need not equilibrate at each adaptive step, and finite staging,
weight clipping, sparse rare-node visits or a remaining host barrier can prevent
the run from reaching that root. Zero allocations have no finite interior root.
Freeze finite weights and discard all calibration rows regardless of whether
the efficiency checks passed.

For uniform `tau_j=1/J`, the common `g_t/J` addition cancels exactly upon an exact
common gauge subtraction. The implementation retains its separate legacy
decrement-only branch, gauge cadence and RNG sequence to preserve bitwise old
trajectories. A hypothetical modification that clips **before** gauge removal
can break this algebra; the independent clipping counterexample is about that
premature-clipping modification, not a defect in the current gauge-then-clip
driver. A clipped adaptive root need not be the unconstrained root above.

Weighted label flatness is
`min_j(C_j/tau_j)/mean_j(C_j/tau_j)`, not flatness of raw visits `C_j`. In addition,
every label must have at least 100 actual visits. Scaling a proportional count
vector down preserves weighted flatness but can leave the ideal label almost
unobserved. Number/order half-stage checks use consecutive clock-time halves,
the correctly paired pre-Gibbs observation label and host features, and at least
50 actual observations per tested label per half. They are efficiency/drift
checks, not proofs that full conditional distributions or phase weights have
equilibrated: distinct distributions can have the same number and order means.

For any finite frozen `b`, physical conditional estimates remain ratios of actual
within-label rewards to actual dwells. For complete cycles let `D_base` and
`D_cavity` be summed dwells. The cavity work estimate remains

`beta W = log(D_base/D_cavity) + b_cavity-b_base`.

Do not replace observed dwell odds by nominal `tau_base/tau_cavity` unless the
true normalizing weights are already independently known. An exact finite
counterexample has `Xi_base=5`, `Xi_cavity=2`, `exp(b_base)=2` and
`exp(b_cavity)=3`: actual label odds are `5/3`, so the corrected ratio is `5/2`;
substituting equal nominal quotas instead incorrectly gives `3/2`. Do not
divide physical phase rewards by a label quota or average per-cycle ratios.
The complete-cycle normalizer remains a summed-reward/summed-dwell ratio, and
the fixed-clock stopping and rare-phase qualifications above still apply.

The independent rational finite-state controls are in
`tests/test_single_walker_label_quotas_independent.py`. They verify the root,
gauge drift, unchanged physical conditionals, Gibbs/tagged/heatbath stationarity,
actual weighted-flatness helpers, and deliberate wrong-quota/work/phase
substitutions. They passed in the coordinated 262-test pure collection.
`tests/test_single_walker_frozen_label_quota_equilibrium_independent.py` adds an
actual 200,000-clock five-node continuum control against independent `N<=3`
nine-dimensional partition integrals. With nonuniform frozen weights, Gibbs,
nonuniform birth/death and residual-vacancy relocation, its complete joint and
conditional number/order laws, frozen-weight identity, support/cache/center
reconstruction and complete-cycle work passed. This is deliberately capped,
small-target implementation evidence, not a dense equilibrium result.

The first execution stopped only at an overrestrictive transport diagnostic:
an edge had 972 accepted moves rather than a borrowed `>1000` cutoff. At ideal
allocation `.02` and degree 3, the expected outgoing proposals on each of its
edges are only `200000*.02*.5/3`, about 667 even before MH rejection. The cutoff
was changed to `>500` as weak bidirectional execution coverage; **all independent
joint, conditional and work tolerances, seed and run length were unchanged**.
The complete control then passed in 4.78 seconds of pytest time (5.31 seconds
external wall time), with 357 MiB maximum RSS and zero swaps. Neither this
diagnostic adjustment nor the pure controls certify dense return or switching.

### Exact necessary normalizer constraints and discarded projection

For one declared physical radius path `0=R_0<...<R_m=sigma`, require the same
activity, diameter and periodic box, infinite hard-pair penalty, zero order and
number umbrellas, and a nontruncating physical cap. These are restrictions on
where a normalizer identity applies, not additional restrictions on host phases.
Nested empty-cavity supports give

`Xi_0 >= Xi_R1 >= ... >= Xi_sigma > 0`.

Consequently the desired allocation-normalizing root
`a_j=b_j-log(tau_j)=-log(Xi_j)+C` is nondecreasing along the radius path. The
matched-particle reduced-Palm identity gives

`a_sigma-a_0 = beta W_sigma = log(zeta V / E_0 N)`.

For a cubic torus with `L>=sigma`, disjoint radius-`sigma/2` hard-particle balls
give `N<=floor(6V/(pi sigma^3))`. Also `Xi_0>=1+zeta V`, since the empty and
one-particle sectors are unconstrained, so
`E_0 N>=P_0(N>=1)>=zeta V/(1+zeta V)`. Combining these results and the nesting
bound `W_sigma>=0` gives the necessary span interval

`max(0,log(zeta V/N_bound)) <= a_sigma-a_0 <= log(1+zeta V)`.

The implementation conservatively uses the ceiling packing bound, with a cap
at least that ceiling, to guard floating-point boundary rounding. This is a
slightly weaker valid interval. At `V=30.8496`, `x=16`, `sigma=1`, the mathematical
integer packing maximum is 58, yielding span bounds 15.36868077 and 19.42912379;
the ceiling choice 59 gives lower bound 15.35158634. An artificially truncating
cap does **not** support the unrestricted endpoint identity: its cavity
normalizer includes the next base population sector. Different activities or
finite soft-pair penalties also invalidate this hard matched-insertion identity.

Order inequalities plus finite endpoint-span bounds form a closed convex
polyhedron with additive-gauge lineality, not literally a cone. A simultaneous
positive-metric Euclidean projection is unique; the implemented opt-in helper
uses unweighted L2. It changes discarded efficiency weights only and is never
applied to frozen production. Arbitrary finite frozen weights are already legal
extended targets, including weights outside this polyhedron; the constraints
identify a necessary condition for **desired quota-normalizing weights**, not
the validity of their conditional physical law. Correcting an impossible
normalizer valley does not determine the true partition functions or prove host
or phase equilibration. A one-pass isotonic correction followed by endpoint
clipping can destroy monotonicity again. Individual clipping must be followed
by a feasibility check; a common additive gauge preserves all differences.
Every discarded projection correction must be archived for weight-increment
replay and distinguished from the allocation update.

The opt-in helper is `scripts/continuum_normalizer_projection.py`.

### Optional positive-volume subset bounds, not implemented constraints

One can additionally bound an absolute physical-family normalizer relative to
an exactly normalized ideal reservoir without prescribing phase odds. Choose
`n` distinct periodic reference sites with minimum torus distance `d_min>sigma`,
and open torus balls of radius `delta<(d_min-sigma)/2`. Each ball has volume
`v_delta=4 pi delta^3/3` when `delta<L/2`. The triangle inequality makes all
configurations with exactly one particle in each ball hard-compatible. Balls
are disjoint. Their `n!` ordered-coordinate assignments cancel the reference
sector factor `1/n!`, giving the positive-volume lower bound

`Xi_0 >= (zeta v_delta)^n`.

For each reference site, omit its particle and put the matched cavity center
inside its ball. Every remaining host is farther than `sigma` from that center.
The center restriction contributes `v_delta/V`, not an unnormalized volume.
The `n` tag events are disjoint through their center balls; the `(n-1)!` host
assignments cancel their own sector factor. Thus

`Xi_sigma >= n zeta^(n-1) v_delta^n / V`.

These are subsets of an unrestricted configuration integral. No reference
registry, occupancy requirement, phase probability or crystal-fragment factor is
added to the sampled target. For the base subset the cap must include sector
`n`; for the cavity subset it must include `n-1`. A certified globally inactive
physical cap remains necessary for interpreting the physical target as
unrestricted. The enlarged uniform-center cavity law equals the fixed-center
normalizer by translation invariance. Anchoring one reference placement merely
gives a conservative subset bound; it does not discard a translation factor
from the full target.

For the 32-site periodic FCC reference, `V=19281/625=30.8496` and
`d_min^2=L^2/8`. With the safely rounded `delta=1/20=.05`, the exact rational
inequality `V^2>512*(1.1)^6` proves `d_min>sigma+2delta`. Using `pi>3.14159` and
rational upper/lower Taylor bounds for exponentials gives the conservative
decimals `log Xi_0>270.246` and `log Xi_sigma>254.283` at `x=16`.

At an unbiased ideal node `I`,
`Xi_I=sum_{k=0}^K (zeta_I V)^k/k!` is exactly known. The desired-root gauge is
`C=b_I-log(tau_I)+log(Xi_I)`. For `b_I=0`, `tau_I=.02` and
`zeta_I=1/1.06448`, the full-Poisson upper bound implies `C<32.893`.
With physical allocations `.30`, the subset results give conservative desired
root bounds `b_0<-238.5569` and `b_sigma<-222.5939`. Such bounds would add
absolute-family upper halfspaces relative to the ideal node; they still would
not identify phase weights. Their geometry, factorial cancellation, normalized
center factor and safe decimals are independently certified in
`tests/test_fcc_positive_volume_normalizer_bounds_independent.py`. They are
mathematical R&D/audit results only and have **not** been added to the production
projection. The minimal nested/span projection is evaluated first.

### Additional exact soft-pair and duplicate-target constraints

The following new bound is independent of cap inactivity. It applies to targets
with the same activity, diameter, radius, box, center measure and common cap `K`,
and with **zero order and number umbrellas**. Let `P(eta)` count each unordered
overlap pair once and let the soft pair potential be `gamma P(eta)`, `gamma>=0`.
The corresponding hard host has support `H={P=0}`. For every finite host, the
overlap graph has a vertex cover `C` with `|C|<=P`, by choosing one endpoint of
each edge. Consequently

`exp(-gamma P) <= sum_{C subset eta} exp(-gamma |C|) 1{eta\C is hard}`.

If the original host satisfies its cavity constraint, every deletion residual
does too. The upper bound may therefore use the residual cavity indicator and
integrate removed coordinates over the entire box, safely overcounting them.
For `r` remaining hosts and `m` removed coordinates, `r+m<=K`, the subset count
`choose(r+m,m)` cancels the common sector factorial into `1/(r! m!)`. Writing
`h_r` for the hard cavity sector and `lambda=zeta V exp(-gamma)` gives

`Xi_soft,K <= sum_{r=0}^K h_r sum_{m=0}^{K-r} lambda^m/m!`
`          <= Xi_hard,K exp(lambda)`.

The lower bound `Xi_soft,K>=Xi_hard,K` follows because the hard subset has zero
soft energy. Thus `0<=log(Xi_soft,K/Xi_hard,K)<=lambda`, with no requirement
that `K` include every possible hard host. The shared cap is essential; changing
the cap adds unmatched sectors. Additional number/order costs generally do not
factor through deletion and invalidate this particular bound.

The soft law conditional on `H` is exactly the hard law. In the convention
`TV(P,Q)=sup_A|P(A)-Q(A)|`, their distance is exactly
`1-Xi_hard,K/Xi_soft,K`, hence at most `1-exp(-lambda)`. For the requested
quota-normalizing root this supplies the necessary linear interval

`0 <= a_hard-a_soft <= lambda`, `a=b-log(tau)`.

At `x=16`, `V=30.8496`, `gamma=25`, `lambda=.00380714309` and the TV upper bound
is `.00379990512` when conservatively rounded upward. An adjusted weight gap of
9.07 between a pure `gamma=25` node and its otherwise identical hard target
cannot represent the desired normalizer difference. It is not evidence of a
new free-energy barrier or a change in the conditional physical target. Under
an actually equilibrated pure soft node, the hard-subset probability is at least
`exp(-lambda)`; applying this conclusion to transient saved hosts would be
incorrect.

Identical ideal targets have identical exact capped normalizers even if only
one label performs the designated heatbath. Their desired-root adjusted weights
must satisfy `a_j=a_k`; raw weights instead satisfy
`b_j-b_k=log(tau_j/tau_k)`. The choice of within-node invariant update does not
alter their normalizer. These intervals/equalities could augment a discarded
efficiency projection without adding targets or prescribing phase odds, but
their implementation is not authorized by the mathematical derivation alone.

Pure independent Fraction controls are saved in
`tests/test_soft_hard_normalizer_bound_independent.py`. They enumerate covers,
shared-cap convolution and the exact TV identity for finite hard-graph targets
with and without cavities, and exhibit failures for different caps, nonzero
number bias and an incorrectly half-counted pair coefficient. All 39 controls
passed in 0.06 seconds of pytest time (0.22 seconds external wall), with 36.8 MiB
maximum RSS and zero swaps. No Monte Carlo or sampler import was involved.
These controls verify the proof, not a production projection augmentation or
dense equilibration.

## Exact single-host matched-cavity jump

Let `b` denote a zero-radius hard-sphere node and `c` its cavity node at radius
`R = sigma`, with the same activity `zeta` and zero physical umbrellas. This jump
is additional to ordinary hops. It is not the two-host Palm exchange.

From `(b, eta, q)` with `N=n>0`, choose a host particle `a` uniformly, remove it,
and propose `(c, eta-delta_a, a)`. Discard the old base center `q`. From
`(c, xi, a)` with `M=m`, restore a host particle at `a`, independently draw a fresh
uniform base center `q`, and propose `(b, xi+delta_a, q)`. The hard supports are
identical under this map: the matched cavity guarantees the restored particle is
compatible with every remaining host.

The reference Campbell identity is

`∫ Σ_{a in eta} F(eta-delta_a,a) M_K(d eta)
 = ∫_{N(xi)<=K-1} ∫ F(xi,a) d a M_K(d xi)`.

To compare the proposals, use common marked coordinates `(xi,a,q)`, where
`m=N(xi)` and both supports hold. Apart from their common global normalization,
the forward flux density with respect to `M_K(d xi) d a d q` is

`e^{b_b} zeta^{m+1} / [(m+1)V]`,

and the reverse flux density, including the new uniform center draw, is

`e^{b_c} zeta^m / V^2`.

The reverse/forward ratio is consequently
`exp(b_c-b_b) (m+1)/(zeta V)`. The acceptances are

`base -> cavity: min(1, exp(b_c-b_b) N/(zeta V))`,
`cavity -> base: min(1, exp(b_b-b_c) zeta V/(M+1))`.

If the two move types are selected with unequal probabilities, multiply each
ratio by its reverse/forward selection-probability ratio. A neighbor-selection
implementation also includes the corresponding graph factors. There is no extra
factorial, squared particle count, or coordinate Jacobian. Reject the forward
move at `N=0`. Reject reverse restoration at `M=K` in a deliberately truncated
toy ensemble; with the physical nontruncating cap such a cavity state cannot
exist. Keeping the cavity center as the base center, rather than refreshing it
independently, would not implement this reverse kernel.

The jump changes the sole host particle number by one and carries no conserved
two-host inventory. At equilibrium, choosing
`exp(b_c-b_b) approximately zeta/rho` makes its acceptance naturally near one
for `N approximately rho V`, without requiring a spontaneously empty insertion
hole. That is an acceptance observation, not a prediction of phase mixing.

## Ideal-reservoir regeneration

At a designated node with zero pair, cavity, order, and number penalties, replace
the entire state by an exact independent conditional draw. Draw

`P(N=n | ideal) = (zeta V)^n/n! / Σ_{r=0}^K (zeta V)^r/r!`, `0 <= n <= K`,

then draw the `n` host coordinates independently and uniformly on the torus and
draw `q` independently from Haar measure. A stable log-weight/CDF implementation
is preferable at large `zeta V`. This is a capped Poisson law, not a Poisson draw
clamped to `K`. Regenerate every coordinate and all derived caches. The resulting
kernel is a conditional heatbath and preserves the extended target. It erases
the previous host's phase memory at that node; reaching and returning from the
reservoir can nevertheless remain slow and correlated. Reservoir returns are
not independent physical-ensemble samples merely because a heatbath occurred.

Choose one designated reservoir node `j_0`, and perform its full independent
heatbath at the same kernel stage whenever the chain visits it. A regeneration
boundary is the completion of that heatbath, not merely an ideal-node arrival.
Conditional on all learned, frozen parameters and with fresh independent
randomness, the post-heatbath law is always the same fixed law at `j_0`,
independent of earlier chain states. Subsequent completed reservoir-to-reservoir
cycles are iid regenerative cycles under that conditional law. This does not
assert unconditional independence across different calibration histories.
The first exact production refresh removes the initial host's dependence on
calibration; exclude observations preceding it and retain only completed
cycles after it for this analysis.
Different ideal nodes, incomplete refreshes, or different within-sweep boundary
stages cannot silently be treated as this single regeneration atom.

For a physical node `j` and phase `alpha`, let `R_alpha,l` be the number of its
complete-sweep clock-time dwells in phase `alpha` during cycle `l`, and let `D_l`
be all complete-sweep clock-time dwells at that physical node in the cycle.
Accumulate these rewards on every sweep, even when coordinate snapshots are
saved less frequently. A global stride greater than one carries its sampling
clock phase across regeneration boundaries; cycle rewards reconstructed only
from such sparse frames are not automatically iid. The phase-probability
estimator is the renewal-reward ratio

`qhat_alpha = Σ_l R_alpha,l / Σ_l D_l`,

not the unweighted mean of the per-cycle ratios `R_alpha,l/D_l`. Long cycles
contribute proportionally more physical observations. Zero-physical-dwell cycles
contribute zero to both sums and should still be retained in the cycle record.
For another observable, replace the phase count by its accumulated physical-node
reward. Under the finite-cap irreducible chain the corresponding integrable
renewal-reward law recovers the invariant physical conditional expectation.
Physical observations within a cycle remain correlated; the independence applies
to complete cycles, not to individual physical states.

Uncertainty can resample whole independent cycles, or use the variance of cycle
residuals `R_alpha,l-qhat_alpha D_l`, only after enough completed cycles resolve
both phases and the relevant number/occupancy support. An unfinished terminal
cycle is not an independent completed-cycle observation. Formal regeneration
does not establish that a feasible run sees rare but important phase cycles.
Collecting a prespecified fixed number of completed cycles gives the cleanest
iid analysis. A fixed-sweep or wall-clock stopping rule retains a
duration-dependent random prefix: the underlying cycle sequence remains iid,
but the conditional observed sample is not an exact fixed-size iid experiment.
Cycle-bootstrap uncertainty for that stopping design is an asymptotic estimate,
not an exact finite-sample unbiased guarantee.
This is a potential route to rigorous independent-cycle statistics, not a report
of completed dense equilibration.

Connected graph support at the empty host, positive birth/death proposal support,
lazy hops, and the Haar-center component yield a finite-cap irreducibility and
aperiodicity route. Any minorization bound is expected to be extremely weak;
formal ergodicity is not evidence that a particular dense run is equilibrated.

## Observation, calibration, and equilibrium evidence

Observe the extended chain at a fixed clock-time point in each complete sweep.
For a physical node `j`, estimate an observable by the conditional ratio

`sum_t 1{J_t=j} A(eta_t,q_t) / sum_t 1{J_t=j}`.

Include every saved physical-node dwell, rejection, and repeated state. Recording
only accepted hops, first arrivals, or transition events generally samples a
biased jump chain. Estimate uncertainty with the actual conditional-ratio time
series and its correlations; visit counts alone are not effective sample sizes.
Do not pool distinct physical activities into one thermodynamic ensemble.

Adapt `b`, auxiliary parameters, or proposal scales only during explicitly
discarded calibration/burn-in. Freeze every target, graph, tempering weight, and
proposal parameter before production; archive their exact arrays and the executed
source bytes/hash. Finite-cell activity scans, if needed to find two populated
basins, are separate physical targets and must remain separately analyzed.

Before any dense claim, require the following staged evidence:

1. Pure exhaustive finite-state tests below pass, including intentional wrong
   ratios that fail detailed balance. They establish formula correctness only.
2. An actual low-density continuum kernel agrees with independent capped
   partition quadrature for node frequencies, full conditional number laws,
   order means, and base/cavity support. Test nonzero auxiliary order and number
   umbrellas, nonuniform insertion proposals, cap boundaries, and cache updates.
3. Independently initialized all-fluid and crystalline single-host histories,
   with independent seeds and identical frozen targets, reach compatible
   physical conditional distributions after separately discarded burn-in.
   Use independent structural observables (including local/global bond order),
   not the Fourier order parameter alone, to confirm both basins.
4. Both histories display repeated reservoir-to-physical returns and genuine
   creation and melting of crystal order, with fluctuating host number and
   crystal occupancy. Predeclare useful uncertainty tolerances for phase weights
   and the number/occupancy distributions; obtain enough correlated-sampling
   precision to resolve them. A few transitions or matching point means do not
   suffice.
5. Where the physical cap is nontruncating, compare direct cavity statistics
   with the exact reduced-Palm deletion identities using uncertainties. Do not
   apply the unrestricted shifted size-bias identity to an artificially capped
   toy target without its boundary correction.

Failure at any stage is a reason to improve the design or extend the calculation,
not to relabel nonstationary histories as equilibrium. The protocol makes no
claim of a faster or completed dense fluid–solid calculation.
