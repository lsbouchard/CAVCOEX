# CAVCOEX

**CAV**ity response at first-order **COEX**istence.

This repository contains the numerical code, frozen input data, derived data,
figures, and tests for Louis-S. Bouchard's study of the extensive response to a
local exclusion cavity at first-order coexistence.  It provides the numerical
validation of the finite-volume response identities, the two-state coexistence
pulse, the square-lattice-gas benchmark, and the hard-sphere reference
calculations.

## Status and scope

The committed data are the frozen production campaign used for the study.  The
repository is intentionally limited to numerical reproducibility material: it
does not contain manuscript sources, submission PDFs, review correspondence, or
release archives.

The code is provided **as is**, without warranties, maintenance, or technical
support.  See [NOTICE.md](NOTICE.md) and [LICENSE](LICENSE).

## Quick start

Create the tested Conda environment, then validate the frozen release:

```sh
conda env create -f environment.yml
conda activate constrained-cavity-nucleation
make test
```

To regenerate all deterministic products and reanalyse the archived lattice
trajectory campaign before testing:

```sh
make reproduce
```

`make reproduce` does not rerun the long Monte Carlo production campaigns; it
uses their archived raw trajectories in `data_raw/`.  The simulation drivers
remain available in `scripts/` and expose their documented command-line options
through `python scripts/<name>.py --help`.

## Repository layout

| Path | Contents |
| --- | --- |
| `scripts/` | Simulation drivers, analytic checks, fitting, reweighting, and figure generation. |
| `tests/` | 109 regression and consistency tests. |
| `data/` | Equation-of-state benchmark data. |
| `data_raw/` | Frozen Monte Carlo trajectories, block records, diagnostics, and external coexistence input. |
| `data_processed/` | Recomputed numerical tables and covariance products. |
| `generated/` | Machine-readable provenance and generated summaries. |
| `figures/` | Vector figures regenerated by the analysis scripts. |

## Reproducibility targets

```sh
make analytic           # exact identities and deterministic hard-sphere checks
make lattice-analysis   # reanalyse the archived square-lattice-gas campaign
make test               # run the regression suite
make reproduce          # analytic + lattice analysis + test
```

The raw hard-sphere and lattice-gas simulation archives are retained so the
analysis can be repeated without a prohibitively long production run.  The
simulation scripts use fixed seeds and supply the exact production settings in
their source and command-line help.

## External data

`data_raw/fernandez2012_coexistence.csv` transcribes Table I of L. A.
Fernández *et al.*, *Physical Review Letters* **108**, 165701 (2012),
<https://doi.org/10.1103/PhysRevLett.108.165701>.  The corresponding source
uncertainty propagation and a separate vacancy-scale sensitivity calculation
are performed by `scripts/hard_sphere_sensitivity.py` and
`scripts/hard_sphere_defect_sensitivity.py`.
